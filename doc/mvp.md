# GoCockpit — MVP

## Objetivo

Crear una aplicación web funcional para monitorizar y administrar un sistema Linux desde el navegador.

## MVP

Estas funcionalidades forman parte del MVP:

* [ ] Servidor web en Go.
* [ ] Interfaz web básica.
* [ ] Información del sistema.
* [ ] Monitorización de CPU.
* [ ] Monitorización de RAM.
* [ ] Monitorización de almacenamiento.
* [ ] Monitorización de red.
* [ ] Lista de procesos.
* [ ] Información de procesos.
* [ ] Gestión básica de procesos.
* [ ] Gestión de servicios `systemd`.
* [ ] Consulta de logs.
* [ ] Autenticación.
* [ ] Sesiones y autorización.
* [ ] Seguridad básica.
* [ ] Tests.
* [ ] Documentación.
* [ ] Deployment funcional.

## Fuera del MVP

Estas funcionalidades no son necesarias para la primera versión, pero podrán implementarse si queda tiempo:

* [ ] WebSocket avanzado.
* [ ] Terminal interactiva mediante PTY.
* [ ] Gestión de Docker.
* [ ] Métricas históricas.
* [ ] Gráficas avanzadas.
* [ ] Gestión avanzada de red.
* [ ] Gestión avanzada de almacenamiento.
* [ ] Sistema de alertas.
* [ ] Auditoría avanzada.
* [ ] Mejoras avanzadas de interfaz.

## Prioridad

El objetivo principal es terminar primero todas las funcionalidades del MVP.

Las funcionalidades fuera del MVP solamente se desarrollarán cuando el MVP esté terminado y quede tiempo disponible.

## Regla

> Primero funcional, después completo y finalmente avanzado.
