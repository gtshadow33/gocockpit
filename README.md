# GoCockpit

Web-based Linux server monitoring and administration dashboard built with Go.

## Objetivo

GoCockpit es una aplicación web para monitorizar y administrar
un servidor Linux desde una interfaz centralizada.

## Objetivo

- Monitorización del sistema
- Monitorización de CPU y memoria
- Gestión de procesos
- Gestión de servicios systemd
- Información de almacenamiento
- Información de red
- Visualización de logs
- Autenticación
- Terminal web
- Gestión de Docker
- Actualización de información en tiempo real

## Tecnologías

- Go
- net/http
- html/template
- HTML
- CSS
- JavaScript
- WebSocket
- Linux
